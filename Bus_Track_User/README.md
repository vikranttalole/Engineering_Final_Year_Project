
# Real-Time Bus Tracking and Passenger Information System for MSRTC

## 📌 Project Overview

The Real-Time Bus Tracking and Passenger Information System is a smart transportation solution developed to improve the travel experience of MSRTC passengers. The system enables real-time tracking of buses using GPS technology and provides passengers with live bus location updates, route information, and estimated arrival details.

The project consists of three major modules:

* Driver Android Application
* Passenger Android Application
* Web-Based Admin Panel

This system helps reduce passenger waiting time, improves transportation efficiency, and provides better communication between passengers, drivers, and transport administrators.

---

## 🎯 Objectives

* Track buses in real-time using GPS.
* Provide live bus location updates to passengers.
* Manage buses, routes, and drivers through an admin panel.
* Improve passenger convenience and transportation management.
* Enhance operational efficiency of public transport services.

## 🚀 How to Run

### Prerequisites

* JDK 8+ (Recommended: JDK 21)
* Apache Tomcat
* MySQL Server
* NetBeans or Eclipse IDE

### Steps

1. Import the database using the provided SQL file.
2. Configure MySQL connection in `DBConnect.java`.
3. Deploy the Admin Panel on Apache Tomcat.
4. Run the Android Driver Application.
5. Run the Android Passenger Application.
6. Access the Admin Panel through a web browser.
